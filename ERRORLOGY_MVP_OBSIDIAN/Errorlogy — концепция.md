# Errorlogy — концепция

**Errorlogy** — рамка (не бренд): изучение ошибок госуправления как **наблюдаемых объектов**.

## Четыре тезиса

1. **Управление = менеджмент** — органы власти под неопределённостью, те же режимы сбоев, что у любого менеджмента.
2. **Должность ≠ компетентность** — власть действовать ≠ способность действовать хорошо; разрыв наблюдаем.
3. **Ошибки через разрывы, не через исход** — фиксируется delta: *заявлено / известно / решено*, а не post-hoc outcome.
4. **Каталог лучше обвинения** — именованный режим из таксономии проверяем; моральный вердикт — нет.
