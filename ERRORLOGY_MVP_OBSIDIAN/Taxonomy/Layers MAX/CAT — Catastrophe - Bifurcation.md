#CAT - Catastrophe / Bifurcation

Catastrophe Theory / Bifurcation Layer: models of abrupt transitions in governance error states after smooth accumulation of control parameters such as weak signals, legal lag, capacity gap, blocker power, opacity, social pressure and incentive misalignment.

## Principle

Many governance failures do not grow linearly. Smooth accumulation of weak signals, legal lag, capacity gap, blocker power, opacity or social pressure can push the system across a bifurcation boundary, causing an abrupt shift to a worse error regime.

**Status in JSON:** nonlinear_transition_and_threshold_layer

## Modes / types (16)

| ID | Name | Definition (brief) |
|----|----------|---------------------|
| `CAT-001` | Fold catastrophe / threshold collapse | A slowly increasing control pressure crosses a threshold and the governance state jumps abruptly to a worse regime. |
| `CAT-002` | Cusp catastrophe / delayed flip with hysteresis | Two control parameters create a region where the system can remain apparently stable until it flips abruptly and does not easily return. |
| `CAT-003` | Swallowtail catastrophe / multi-stage lock-in | Several historical choices create multiple local equilibria and abrupt jumps between implementation states. |
| `CAT-004` | Butterfly catastrophe / overcontrolled policy surface | Too many interacting control parameters produce unstable policy surfaces with sudden shifts under small parameter changes. |
| `CAT-005` | Hyperbolic umbilic / competing control axes | Two state variables and several controls generate a saddle-like failure where two governance dimensions destabilize each other. |
| `CAT-006` | Elliptic umbilic / circular blame trap | Several actors deflect responsibility in a loop, making attribution and correction without circulation. |
| `CAT-007` | Parabolic umbilic / channel collapse | Information or decision flow collapses when one channel becomes overloaded while another remains structurally constrained. |
| `CAT-008` | Hysteresis of institutional correction | Once the error regime has shifted, reducing the original pressure is insufficient to return the system to the previous state. |
| `CAT-009` | Bifurcation set crossing | The system crosses a boundary in control-parameter space where stable governance states disappear or split. |
| `CAT-010` | Critical slowing before collapse | The system becomes slower to recover from perturbations before a regime shift. |
| `CAT-011` | Flickering between regimes | The governance system temporarily alternates between regimes before locking into one. |
| `CAT-012` | Control-parameter masking | The visible state looks stable because the true control parameters are hidden, mismeasured or politically suppressed. |
| `CAT-013` | Small perturbation / large governance jump | A minor shock causes a disproportionate governance response because the system was already near a bifurcation surface. |
| `CAT-014` | Multi-attractor basin governance | The same policy system has several stable but incompatible attractors, and small differences in initial conditions determine the final regime. |
| `CAT-015` | Catastrophic loss of optionality | A series of small delays and commitments removes alternatives until the remaining path is structurally bad. |
| `CAT-016` | Catastrophe-induced narrative inversion | After a sudden regime shift, actors reinterpret prior weak signals to fit a new narrative, distorting learning. |
