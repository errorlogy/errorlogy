# Мета-измерения (R, O, A, C, T, X)

Поперечные оси, по которым режимы ошибок могут быть размечены в `atomic_modes.meta_dimensions`.

| Код | Смысл |
|-----|--------|
| `R` | Representation error: distorted, incomplete, filtered, or compressed view of reality |
| `O` | Objective misalignment: effective objective diverges from declared/institutional objective |
| `A` | Aggregation nonlinearity: collective aggregation does not preserve rationality or preference coherence |
| `C` | Coordination entropy: costs, vetoes, jurisdictional conflicts, and responsibility diffusion prevent improvement |
| `T` | Temporal instability: short-horizon decisions compound into long-horizon degradation |
| `X` | Anti-consensus / divergence: agent interaction prevents convergence or produces false consensus |
