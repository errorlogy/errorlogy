# LAC — Agent Strategy Contribution

Agent / Strategy Contribution Layer: analytical, non-accusatory attribution of contribution of homo-agents and multi-agent strategies to error activation and system regimes.

## Принцип

Errorlogy does not infer guilt from outcome. It estimates analytical contribution of strategies to error activation, with fuzzy membership, confidence and evidence-grade separation.

**Статус в JSON:** non_accusatory_contribution_layer

### Methods

- `LAC-M-001` — Counterfactual ablation
- `LAC-M-002` — Shapley value contribution
- `LAC-M-003` — Causal path contribution
- `LAC-M-004` — Network error-diffusion centrality
- `LAC-M-005` — Strategic role decomposition
- `LAC-M-006` — Blocker danger scoring
