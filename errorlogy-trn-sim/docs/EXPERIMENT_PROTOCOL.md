# Протокол экспериментов

## 1. Цель

Найти параметры, при которых синтетическая информационная среда TRN переводит агентную сеть из состояния консенсуса в состояние поляризации или антиконсенсуса.

## 2. Эксперименты

### A. Baseline

\[
\lambda=0
\]

Цель: проверить естественную динамику сети без внешнего поля.

### B. Sweep по интенсивности TRN

\[
\lambda\in\{0,0.1,0.2,\dots,1.2\}
\]

Цель: найти порог фазового перехода.

### C. Grid по критической фильтрации и устойчивости

\[
q\in\{0.25,0.45,0.65,0.80\}
\]

\[
r\in\{0.25,0.45,0.65,0.80\}
\]

Цель: оценить защитный эффект \(q,r\).

### D. Sweep по эхо-камерности

\[
\chi\in\{0.5,1.0,1.5,2.0,2.5,3.0,4.0\}
\]

Цель: определить, когда локальная самоподдержка нарратива вызывает кластеризацию.

### E. Sweep по ширине окна доверия

\[
h\in\{0.15,0.25,0.35,0.45,0.60,0.80\}
\]

Цель: проверить, как bounded confidence влияет на фрагментацию.

## 3. Повторы

Каждый сценарий запускать минимум:

\[
R=10
\]

раз с разными seed.

Для быстрых тестов допустимо \(R=3\). Для итогового отчёта желательно \(R=30\).

## 4. Выходные данные

Для каждого запуска сохранить:

- final consensus;
- final polarization;
- final extreme_share;
- final entropy;
- final anticonsensus flag;
- TRN risk index;
- все параметры запуска.

## 5. Итоговые таблицы

Таблица 1: sweep по \(\lambda\).  
Таблица 2: grid по \(q,r\).  
Таблица 3: sweep по \(\chi,h\).  
Таблица 4: сравнение \(R_{TRN}\) и фактической частоты антиконсенсуса.

## 6. Критический вывод

Агент должен вернуть:

1. эмпирический порог \(\lambda_{crit}\);
2. параметры, которые сильнее всего увеличивают риск;
3. параметры, которые сильнее всего стабилизируют систему;
4. ограничения модели;
5. предложения по следующей версии модели.
