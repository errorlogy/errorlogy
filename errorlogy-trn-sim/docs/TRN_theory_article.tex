\section{Abstract}
We consider the synthetic TRN agent model as a parameterized information environment. The model is intended for analyzing consensus, polarization, fragmentation, and anticonsensus. Real personal data and real platform APIs are not used.

\section{Agent model}
Each agent is defined by vector
\[
x_i(t)=(b_i(t),e_i(t),q_i(t),r_i(t),m_i(t)).
\]

\section{Dynamics}
\[
b_i(t+1)=clip_{[-1,1]}[b_i(t)+\Delta t(S_i(t)+I_i(t)+\eta_i(t))].
\]

\section{TRN field}
\[
I_i(t)=\lambda m_i(1-r_i)(1-q_i)A_i(t)(P_i(t)-b_i(t)).
\]

\section{Metrics}
Consensus $C$, polarization Pol, extremity Ext, entropy $H$, and index $R_{\mathrm{TRN}}$ characterize system regimes.

\section{Safety scope}
Synthetic agents and artificial graphs only; no real targeting or influence instructions. See \texttt{SAFETY\_AND\_SCOPE.md}.
